# Bilibili SESSDATA Helper

这是一个独立的 Tabbit/Chrome 辅助扩展，用来从当前浏览器登录态里读取 B站 `SESSDATA`。

## 安装

1. 打开 Tabbit 的扩展管理页面。
2. 打开开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择这个目录：

```text
E:\Projects\ai\video-sub-md\tools\bilibili-sessdata-helper
```

## 使用

1. 在同一个 Tabbit 浏览器里登录 `https://www.bilibili.com/`。
2. 点击扩展图标。
3. 可以选择：
   - 复制 `SESSDATA`
   - 下载 `bilibili.txt`

推荐把下载文件保存为：

```text
E:\Projects\ai\video-sub-md\cookies\bilibili.txt
```

这个扩展不会上传 Cookie，只在本地读取当前浏览器的 B站 Cookie。
